---
title: Get IOTA Tokens
---

IOTA faucet is a helpful tool where IOTA developers can get free test IOTA tokens to deploy and interact with their programs on IOTA's Devnet and Testnet networks. There is no faucet for IOTA Mainnet...

## Prerequisites

To request tokens from the faucet, you must own a wallet address that can receive the IOTA tokens. See the [Get IOTA Address](./get-address.mdx) topic if you don't already have an address or need to create a new one.

## Request test tokens through the online faucet {#online-faucet}

https://faucet.iota.io/: Visit the online faucet to request IOTA tokens.

How to use:

1. Connect your wallet or paste your wallet address in the address field.
1. Use the network dropdown to select the correct network.
1. Click the **Request IOTA** button. 

To request more IOTA, refresh your browser and click the Request IOTA button again. The requests are rate limited, however, so too many requests results in a waiting period before you are able to request more tokens. 

### Return unused Testnet IOTA

The Testnet faucet drains from a finite pool of IOTA. If the pool empties, it disrupts faucet service for the rest of the community. To help ensure this doesn't happen, you can use the online faucet to return your unused IOTA to the pool.

There are two ways to return unused Testnet IOTA:

- Connect your wallet to the online faucet, and click the **Return tokens to faucet** button. Approve the transaction using your wallet and your Testnet IOTA are returned to the pool.
- If you prefer not to connect your wallet, click the **Copy** button to the right of the return address and send the tokens via a separate transaction.

## Request test tokens through the CLI

If you are using the Devnet or Testnet networks, or you spun up a local network, you can use the [IOTA CLI](../../../references/cli/client.mdx) to request tokens for your address. The `iota client faucet` uses the active network and active address that is currently set in the IOTA CLI by default, but you can specify custom data through the following two arguments:

- `--address` argument to provide a specific address (or its alias),
- `--url` argument to provide a custom faucet endpoint.

## Request test tokens through wallet

You can request test tokens within [IOTA Wallet](https://github.com/iotaledger/iota-app-docs/blob/main/iota-iota-wallet.md#add-iota-tokens-to-your-iota-wallet).

## Request test tokens through cURL

Use the following cURL command to request tokens directly from the faucet server:

```
curl --location --request POST 'https://faucet.devnet.iota.io/v1/gas' \
--header 'Content-Type: application/json' \
--data-raw '{
    "FixedAmountRequest": {
        "recipient": "<YOUR IOTA ADDRESS>"
    }
}'
```

If you're working with a local network, replace `'https://faucet.devnet.iota.io/v1/gas'` with the appropriate value based on which package runs your network:

- `iota-faucet`: `http://127.0.0.1:5003/gas`
- `iota`: `http://127.0.0.1:9123/gas`

## Request test tokens through TypeScript SDK

You can also access the faucet using the IOTA TypeScript-SDK.

```typescript
import { getFaucetHost, requestIotaFromFaucetV0 } from '@iota/iota-sdk/faucet';

// get tokens from the Devnet faucet server
await requestIotaFromFaucetV0({
	// connect to Devnet
	host: getFaucetHost('devnet'),
	recipient: '<YOUR IOTA ADDRESS>',
});
```

## Test tokens on a local network

If you are running a local IOTA network, you can get tokens from your local faucet. See the [Connect to a Local Network](./local-network.mdx#use-the-local-faucet) topic for details.
